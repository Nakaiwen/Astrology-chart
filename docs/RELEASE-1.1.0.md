# 星圖室 1.1.0：月運與年運

## 本次新增

- 本命盤、月運、年運三個入口，沿用出生資料。
- 月運含太陽、水星、金星、火星及五顆慢行星；年運以五顆慢行星整理十二個月。
- 主要相位採 1° 容許度，計算精確時刻、跨期區間、逆行重複相位與未精確但仍在容許度內的接觸。
- 白話重點、完整時間表、月份篩選、JSON、解盤提示及列印／另存 PDF。
- 觀察時區與出生時區分開；出生時間未知時排除本命月亮與軸點，亦不作宮位提示。
- 修改資料後標示舊結果並停用匯出；可取消計算。

## 更新方式

1. 完整解壓縮更新包。
2. 將 `Astrology-chart` 內的檔案合併／覆蓋至 `/Users/nakai/Documents/GitHub/Astrology-chart`。更新包不含 Git 歷史。
3. 開啟最外層 `index.html`；新版頁尾為 v1.1.0，頂部有「本命盤／月運／年運」。
4. 使用 GitHub Desktop 選擇這個儲存庫，提交更新後 Push origin。Pages 維持 main / root 的既有設定。

## 驗證

- TypeScript 型別檢查與正式建置通過。
- 原有 11 項本命計算檢查通過；新增 9 項行運檢查通過，包含閏月、夏令時間、跨零度、轉向點短暫接觸、逆行三次精確相位、跨月邊界、持續相位、未知出生時間及取消。
- 2026 年合成範例產生 33 段相位期間、32 次精確相位；所有精確時刻回算黃經角距誤差低於 0.000002°。
- 另以 Python 原生 Swiss Ephemeris 交叉核對 32 次精確相位，最大角距誤差約 0.000000092°。
- 行運 JSON 通過原 astrology-skill schema；實際瀏覽器匯出的年度 JSON 也通過。
- 瀏覽器核對月運 32 段、年運 33 段、12 個月概覽、11 月篩選 7 段、下載 JSON、手動複製備援及資料變更後的匯出停用。
- 手機寬度容器完成月運計算；文件寬度與可用寬度相符，無橫向溢出。
- 正式入口仍為內嵌程式、樣式與 WASM 的單一 HTML。本次瀏覽器驗證採 HTTP 預覽，未直接操作使用者 Mac 的 file:// 視窗。

GitHub 寫入回覆 403（Resource not accessible by integration）；本更新包已完成，線上儲存庫尚未由此工作階段更新。
